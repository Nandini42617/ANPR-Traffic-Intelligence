# 🚦 VigilantFlow — ANPR Traffic Intelligence System

> **An AI-powered traffic intelligence platform for vehicle detection, automatic number plate recognition, vehicle tracking, trajectory analysis, and intelligent alert generation.**

VigilantFlow combines **Computer Vision, AI/ML, OCR, vehicle tracking, geospatial visualization, and a modern web dashboard** to transform traffic-camera footage into actionable traffic intelligence.

---

## 📌 Overview

Traditional traffic monitoring systems often require continuous manual observation of camera feeds. VigilantFlow automates this process by analyzing traffic videos and extracting useful information such as:

* 🚗 Vehicle Detection
* 🪪 Automatic Number Plate Recognition (ANPR)
* 🎯 Vehicle Tracking
* 🔗 Vehicle–Plate Association
* 🧠 Temporal OCR Consensus
* 🌐 Global Vehicle/Event IDs
* 📍 Camera-Based Trajectory Tracking
* 📊 Traffic Analytics
* 🚨 Watchlist-Based Alerts
* 🎥 Processed/Annotated Video
* 🗺️ Interactive New Delhi Map Visualization

The system follows a **FastAPI backend + React/Vite frontend** architecture.

## 🪪 Automatic Number Plate Recognition

VigilantFlow performs **Automatic Number Plate Recognition (ANPR)** using a multi-stage computer vision pipeline.

### ANPR Pipeline

```text
Traffic Video
      ↓
Vehicle Detection
      ↓
Vehicle Tracking
      ↓
Number Plate Detection
      ↓
OCR
      ↓
Temporal Consensus
      ↓
Vehicle ↔ Plate Association
      ↓
Global Detection Event
```

The multi-stage approach allows the system to combine vehicle detection, tracking, plate detection, and OCR into a single intelligence pipeline.

---

## 🎯 Vehicle Tracking

Detected vehicles are tracked across frames to maintain a consistent identity during their appearance in the video.

The backend maintains information such as:

* Local Track IDs
* Global IDs
* Camera Association
* Detection Timestamps
* Vehicle Class
* Plate Information

This allows observations from multiple frames to be associated with the same vehicle.

---

## 🧠 Temporal OCR Consensus

Instead of depending on a single OCR frame, VigilantFlow aggregates plate observations across multiple frames.

This helps handle situations such as:

* Motion blur
* Partial plate visibility
* Occlusion
* Low-resolution frames
* Unreliable individual OCR results

The system uses accumulated observations to improve the reliability of the final recognized plate.

# 🚨 Intelligent Alert System

VigilantFlow includes a **watchlist-based alert mechanism**.

Operators can add vehicle number plates to the watchlist and assign categories.

### Example Categories

* 🚗 Stolen Vehicle
* ⚠️ Suspicious Vehicle

The backend compares recognized plates against active watchlist entries.

### Watchlist Data

Each watchlist entry contains:

```text
id
plate
category
addedAt
priority
notes
```

When a recognized plate matches an active watchlist entry, the system can generate a corresponding alert event.

# 🔐 Data Integrity & Processing Safety

VigilantFlow uses **source fingerprinting** to identify video sources and help protect asynchronous processing jobs from becoming associated with stale or changed input files.

The backend uses **SHA-256 source fingerprints** as part of this processing-safety mechanism.

This helps ensure that long-running processing jobs remain associated with the intended source.

# ⚠️ Current Limitations

VigilantFlow intentionally avoids presenting unsupported information as real-world measurements.

For example:

```text
Average Velocity → N/A
Estimated Delay  → N/A
```

when sufficient observations are not available for reliable calculation.

Similarly, when there are no active bottlenecks or insufficient historical observations, the dashboard displays an **honest empty state** rather than fabricated information.

> The current camera feeds are demonstration video sources rather than live CCTV/IP streams.
